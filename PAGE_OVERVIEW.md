## 🚀 Interactive Elements

### Buttons
- Hover: Color darkens
- Click: Slight scale
- Disabled: Reduced opacity

### Links
- Hover: Color changes to red
- Underline on hover (text links)

### Cards
- Hover: Shadow expands
- Cursor: Pointer

### Images (Gallery)
- Hover: Scale 1.1
- Click: Opens modal
- Modal: Click outside to close

### Forms
- Focus: Red ring appears
- Error: Red border + message
- Success: Green message banner
